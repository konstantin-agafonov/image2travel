# 19. Безопасность, лицензии и приватность

[Оглавление](README.md) · Далее: [тесты](20-testing-and-evaluation.md)

## Минимум пользовательских данных

Фото остаётся у host. Сервер получает fingerprint и нужные ограничения, не имя/контакты и не весь диалог. Аккаунты, таблицы user/trip/session и автоматическая телеметрия отсутствуют. Экспорт добровольный и удаляется по TTL.

Паспорт означает только country code, не номер/скан документа. Мобильность — добровольное описание требований, не медицинские диагнозы. Эти входы не сохраняются в каталог/логи.

Внешним провайдерам передаются только необходимые публичные координаты/даты/транспорт/валюта. Не отправлять фото, полные briefs, частные адреса или чувствительные места. Кэш не хранит пользовательские сессии; данные запроса минимизированы.

## Сетевой доступ

- Allowlist известных provider domains/paths и разрешённых официальных страниц, HTTPS по умолчанию.
- Проверка DNS/IP и каждого redirect: блокировать loopback, private/link-local, metadata endpoints; localhost-провайдер допускается только явной доверенной конфигурацией оператора, не аргументом tool.
- URL из OSM/Wikidata/wikitext — недоверенный кандидат; не автоматический fetch.
- Таймауты, ограничение тела и распаковки, безопасный JSON/XML/HTML-парсинг, запрет внешних сущностей XML.
- API-ключи из env, не в seed, source URLs, отчётах и cache_key.
- Не давать пользователю tools «произвольный HTTP», «выполни SQL» или «прочитай путь».

## Недоверенное содержимое

Внешние страницы и источники — данные, не инструкции для host. Не выполнять embedded команды, не подставлять текст в shell/SQL. YAML — safe_load, SQL — параметры, HTML — извлечение разрешённых полей. Ответы не содержат активного произвольного HTML или команд из источника.

## Локальная файловая система

Все пути строятся сервером внутри настроенного DATA_DIR. UUID-имена, ограниченные MIME/extension/size, запрет traversal, symlink-выхода и абсолютного пользовательского пути. DB и raw не выдаются через file resource.

Права на runtime-каталог ограничить пользователем процесса. Бэкапы содержат экспорты только при осознанной настройке. Cleanup не удаляет произвольные пользовательские файлы; orphan-очистка ограничена управляемыми подкаталогами.

## Безопасность рекомендаций

Не раскрывать точную геолокацию частных домов, чувствительных природных объектов и опасных/закрытых мест. Не предлагать trespassing, нарушение правил дронов/костров, выход на закрытые тропы или вред экосистемам ради кадра.

Критичный unknown/конфликт/старое ограничение не скрывается. Визовые/медицинские/правовые гарантии не обещаются. Advisories указываются с issuer, scope и датой, не как универсальная оценка риска.

## Лицензионный gate

До публикации каждого источника проверить хранение, производные данные и атрибуцию. Отдельно проверить распространение ODbL-данных в seed/SQLite и CC BY-SA-текстов; не считать техническую нормализацию освобождением от лицензии.

До коммерческого запуска перепроверить API-тарифы и usage policies. Бесплатные demo/public services не имеют автоматически подходящего SLA или коммерческого разрешения. Общая матрица — [источники](10-data-sources.md).

## Логи

JSON в **stderr** при stdio. Логировать request ID, tool name, duration, provider, error code, catalog version; не фото, паспортные входы, полный маршрут, tokens или raw HTTP headers. Debug-режим явно предупреждает о возможных локальных данных и тоже редактирует секреты.

# 18. Ответ пользователю и экспорт

[Оглавление](README.md) · Далее: [безопасность](19-security-and-privacy.md)

## Ответ в чате

Host превращает JSON в Markdown, сохраняя предупреждения и происхождение данных. Самостоятельный экран и интерактивная карта не нужны в MVP.

1. **Что стоит за фото:** короткая интерпретация желаемого впечатления.
2. **До трёх концепций:** направление, совпадение, потери, сезон, crowd, бюджет, транспорт, confidence, sources и допущения.
3. **Маршрут по дням:**

   | День | Утро | День | Вечер | Логистика | План B |
   |---|---|---|---|---|---|

   Для блока — время, точка/координаты, ссылка, длительность, стоимость, бронь и доступность.
4. **Смета:** прибытие (если рассчитано), жильё, транспорт, еда, входы/активности, резерв 10–15 %. Диапазон, person/group, nights/days, валюты и дата расчёта.
5. **Практика:** въезд/документы с применимостью и manual checks, одежда, страховка, бронь, местные правила, безопасность, бережное поведение.
6. **Инструкция по впечатлению:** свет, темп, точка просмотра, погода и план B.
7. **Прозрачность:** verified/editorial/estimated/unknown/stale, дата источников, blockers и непроверенные условия.

Не превращать все источники в нечитаемый дамп: ссылки привязаны к соответствующему факту, итоговый список компактный. Атрибуция OSM/Open-Meteo/текста добавляется там, где используются данные.

## Markdown

Основной экспорт `.md`: UTF-8, тот же маршрут и прозрачность, ссылки и атрибуции. Это не только красивый текст без предупреждений из ValidationReport.

## ICS

Одна активность — VEVENT, стабильный UID внутри экспортируемого маршрута, DTSTART/DTEND, DTSTAMP, location, description и URL. Для повторного экспорта того же неизменного маршрута event IDs сохраняются детерминированным расчётом, без сохранения поездки в БД.

Обрабатывать escaping, переносы/folding строк, CRLF и timezone: UTC timestamps либо корректный TZID/VTIMEZONE. Не ставить плавающие локальные даты без часового пояса. Неизвестное время не превращать в фиктивную бронь; такой пункт пропускается или all-day с явной пометкой «план, не подтверждённое событие».

## GeoJSON

FeatureCollection выбранных POI; координаты `[lon, lat]`, свойства day/time/title/source/status. LineString добавлять только при наличии лицензированной реальной geometry либо с явной маркировкой schematic. Прямая между точками не является пешеходной тропой.

## Файлы

- Сервер создаёт UUID-имя в `<DATA_DIR>/files/exports/` и запись files, возвращает file_id и `image2travel://files/{id}`.
- Экспорт ограничен размером, default TTL 7 дней; tmp — до 24 часов.
- Пользователь не задаёт путь. Доступ через resource, не статическую папку и не публичную ссылку.
- Создание — tmp → atomic rename → metadata; cleanup удаляет только зарегистрированные/управляемые файлы с проверкой пути.
- Экспорт сохраняет содержимое поездки: сообщить пользователю о сроке хранения. Это не сервис аккаунтов/сохранённых поездок.

PDF, публичная ссылка и интерактивная карта — после MVP, с отдельной моделью доступа/приватности.
